Prompt 可以告訴模型角色、任務與輸出格式，但它不能保證每一個步驟真的被執行。

假設你在 System Prompt 寫下：「先查工作表，找不到再查 Confluence，最後附上來源。」模型可能遵守，也可能直接根據語言模式回答；它甚至可能先說「我幫你查一下」，卻沒有真正呼叫任何工具。

## 四個不同層次

- **Prompt**：描述期待的行為。
- **Policy**：定義不能違反的規則。
- **Tool**：讓 AI 能讀取資料或執行操作。
- **Workflow**：用程式決定步驟、條件、重試與結束方式。

Data Machi 後來將規則拆成不同優先層級，並在程式中檢查模型是否真的發出工具呼叫。若模型只輸出等待語句，工作流會要求它重新執行，而不是把一句「請稍等」當成最終答案。

## 小白版比喻

Prompt 像員工手冊，Workflow 像公司的系統流程。手冊寫著「報帳前要主管簽核」，不代表每個人一定會照做；真正可靠的系統會在沒有簽核時阻止送出。

## 踩坑筆記

當規則愈來愈多時，不要只把 Prompt 寫得更長。先判斷哪些內容是語氣偏好，哪些是必須由程式保證的業務規則。
