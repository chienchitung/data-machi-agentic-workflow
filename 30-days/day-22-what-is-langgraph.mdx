LangGraph 可以把 Agent 工作拆成一張有狀態的圖。它的核心不是「把流程畫漂亮」，而是讓每一步、每個條件與目前進度都能被明確管理。

## 三個基本概念

- **State**：保存目前任務資訊，像團隊交接時使用的接力棒。
- **Node**：執行工作的節點，可以是模型、工具或一般程式。
- **Edge**：決定下一步走向，也可以根據條件選擇不同路徑。

Data Machi 目前的 Graph 主要包含 Agent 與 Action。Agent 判斷是否呼叫工具；Action 執行工具；結果回到 Agent 再次判斷。若不再需要工具，流程結束並輸出答案。

```text
START → Agent → Action → Agent → END
```

## 白箱思維

傳統 Agent loop 很多決策藏在模型內部。LangGraph 讓開發者把部分規則寫成程式，例如工具結果為空時改查其他來源、重試超過次數就停止，或高風險操作前暫停。

## 踩坑筆記

LangGraph 不是用來取代所有 Prompt。模型仍負責語意理解，程式則負責必須確定執行的流程。兩者應分工，而不是互相排斥。
