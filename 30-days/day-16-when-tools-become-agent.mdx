一個 Tool 只負責執行特定能力，例如查詢工作表或搜尋文件。Agent 則需要根據任務判斷：要不要使用工具、使用哪一個、取得結果後下一步是什麼。

## 核心差別是決策循環

如果程式固定規定「收到問題就查 PDF」，這是一條自動化流程。當模型能根據問題選擇 PDF、Sheets、Trello 或 Confluence，並在結果不足時改變策略，就開始具備 Agent 特徵。

Agent 並不代表 AI 擁有自由意志。它只是被允許在預先定義的工具、規則與結束條件中做選擇。

## Data Machi 實戰

Data Machi 的 Coordinator 會綁定所有可用工具。模型收到問題後，可以輸出 Tool Call；工具執行結果會再回到模型，讓它決定繼續查詢或產生答案。

## 如何判斷是否真的需要 Agent？

如果任務步驟固定、條件清楚，傳統程式流程通常更穩定。只有當輸入變化大、工具選擇需要語意判斷，或資料不足時要動態調整，Agent 才真正有價值。

## 踩坑筆記

不要把「呼叫一次 API」包裝成 Agent。Agent 的重點不是名稱，而是是否存在觀察結果、重新判斷與選擇下一步的能力。
