讓 AI 自動查資料的風險通常較低，但當 Agent 可以寄信、更新專案、刪除文件或修改資料時，就不能只依賴模型判斷。

## Human-in-the-loop 是什麼？

它代表工作流可以在特定節點暫停，把目前狀態與預計動作交給人類檢查。使用者可以批准、修改輸入或拒絕，之後流程再從原位置繼續。

## 哪些地方需要人工介入？

- 對外寄送訊息或報告。
- 修改、刪除或覆蓋企業資料。
- 高成本或大量 API 操作。
- 模型缺少關鍵條件，需要人類補充。

## 讀取與寫入應分級

企業 Agent 可以先從 Read-only 開始：查詢資料、整理文件與產生草稿。等來源追溯、權限與稽核成熟後，再逐步開放 Write Action。

Data Machi 目前主要聚焦於讀取與分析；完整的 interrupt、resume 與高風險寫入審批，可以作為下一階段 LangGraph 藍圖。

## 踩坑筆記

畫面上放一個「確認」按鈕，不等於真正的 Human-in-the-loop。系統必須保存流程狀態，確保批准後能從原節點恢復，而且操作內容不能在批准前已經執行。
